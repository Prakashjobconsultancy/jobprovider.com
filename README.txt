PRAKASH JOB CONSULTANCY WEBSITE

Files:
- index.html: website content
- style.css: responsive layout and visual styling
- script.js: mobile navigation and current year

How to preview:
1. Extract this ZIP.
2. Open index.html in a web browser.

How to publish:
Upload the three files to your hosting provider's public_html (or website root) folder.
You can use a domain purchased from a domain registrar and connect it to your hosting.

Before publishing:
- Confirm the phone numbers and email are correct.
- Add the real business address, if you want it shown.
- Do not upload Aadhaar/PAN card images or other identity documents to the public website.
- The page currently uses a contact-by-phone/email flow; it does not store applications in a database.
